# SyntaxWear - Tênis e Sneakers Online

A **SyntaxWear** é um projeto de landing page de e-commerce focada na venda de tênis e calçados. O site foi desenvolvido com foco em oferecer uma experiência visual moderna e responsiva para usuários que buscam qualidade, estilo e conforto.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização modular com foco em componentes e responsividade.
- **Google Fonts**: Utilização da fonte "Ubuntu" para uma tipografia limpa e moderna.
- **JavaScript**: Estrutura inicial preparada para interatividades futuras.

## 📁 Estrutura do Projeto

O projeto segue uma organização de pastas focada em manutenibilidade:

```text
/
├── index.html          # Página principal da aplicação
├── README.md           # Documentação do projeto
└── src/
    ├── css/            # Estilos organizados por módulos
    │   ├── base.css    # Estilos globais e reset
    │   ├── variables.css # Definições de fontes e variáveis
    │   └── components/ # Estilos específicos de componentes (header, footer, etc.)
    ├── images/         # Ativos visuais (banners, ícones, logos, produtos)
    └── js/             # Scripts para interatividade
```

## ✨ Funcionalidades Principais

- **Design Responsivo**: Adaptado para diferentes tamanhos de tela (desktop e mobile).
- **Menu Mobile**: Menu lateral acessível através de ícone de hambúrguer em telas menores.
- **Seção Hero**: Destaque principal com chamadas para ação (CTAs).
- **Categorias de Produtos**: Atalhos visuais para categorias (Casual, Esporte, Moderno, Futurista).
- **Grid de Produtos**: Exposição visual dos modelos disponíveis, incluindo o destaque "Krypton One".
- **Rodapé Completo**: Inclui formulário de newsletter, links de navegação e redes sociais.

## 🎨 Design

O estilo visual da SyntaxWear utiliza tons modernos (roxo/violeta) e tipografia clara. Os botões possuem efeitos de transição (hover) para melhorar a experiência do usuário.

## 🛠️ Como Executar

1. Clone o repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Para desenvolvimento, recomenda-se o uso da extensão "Live Server" no VS Code para visualizar as alterações em tempo real.
